## 0. 背景与目标

- 2026-09-24 收市前半小时，"海峡两岸"概念突然爆发，免费历史数据（Baostock，盘后更新）抓不到盘中突袭。
- **目标**：盘中自动监控**全板块**异动，第一时间提示操盘手，无需全程盯屏。
- 这是"外脑"北极星——**帮操盘手省盯盘/复盘时间**——的核心盘中环节，不是额外需求。
- 双轨并行、互为兜底：
  - **A 轨（现成）**：同花顺免费版板块异动雷达，**0 成本、当天能用**，先兜底；
  - **B 轨（自建）**：AkShare + 后台常驻 + **微信推送 + 系统联动 + 自动复盘**，长期主力。

### 为什么需要 B（现成软件覆盖不了的部分）

| 全板块自动监控 | 板块多需**逐个勾选**、行业/概念分开 | 全板块自动，新板块自动纳入 |

| **推送到微信** | ❌ 只推它自己 APP | ✅ 企业微信/Server酱 |
| 结合持仓/候选池/大盘/舆情判断 | ❌ | ✅ |
| 自动留痕、复盘信号胜率、历史回测 | ❌ | ✅ |
| 成本 | 免费（L2 几百/年） | 免费（开发时间） |

## 1. A 轨：同花顺免费版配置 SOP（照着点，今天完成）

> 入口随版本可能略有差异，以实际界面为准；以下基于同花顺官方帮助与公开教程。

### 1.1 手机 APP（推荐，人在外面也能收）
1. 打开同花顺 APP → 底部「**行情**」→ 上方「**板块**」。
2. 板块页右上角「**铃铛（预警）**」图标 → 选择「**板块异动雷达**」。
3. 勾选要监控的板块：能全选则全选（行业 + 概念）；不能全选则优先勾选关注方向。
4. 设置异动阈值：**涨幅**（建议 2.5%~3%）、**成交量/量能变化**（放量），保存。
5. 关键：到手机系统设置 → 通知 → 允许同花顺**通知/横幅/声音**，否则锁屏收不到。

### 1.2 电脑 PC 端（盯盘时用，"鹰眼盯盘"）
1. 顶部菜单 → 「**鹰眼盯盘**」→ 点「**设置**」弹出盯盘条件。
2. 在需要的预警条件前打勾（涨幅、量比、放量、涨停等），设好参数。
3. 「个股雷达」中：**保持监视** = 每次满足都提醒；取消 = 只提醒一次（建议板块用"只预警一次"防刷屏）。

### 1.3 A 轨局限（B 轨补齐）
- 只在同花顺自己的 APP/PC 弹窗，**要登录、要开着、要给通知权限**；
- **不能推微信**、不能和策略/持仓联动、不能自动记录复盘；
- 板块可能要手选；"涨停家数/涨停集中度/股吧情绪"等复杂条件设不了。

### 1.4 通达信是否开源 & 平台×设备能力矩阵

**通达信不是开源软件**：它是深圳市财富趋势科技股份有限公司（上市公司，688318）的商业**闭源**终端，软件本体**无源代码**（官网称"产品均来源于自主开发"）。但其**公式系统开放**——可用专有公式语言自编指标/条件选股/预警（导出 .tn6），网上流传的"通达信源码"是**用户写的指标公式**，不是软件本体源码。

**平台 × 能力矩阵（2026-09-24 调研）**
| 能力 | Win 通达信 | Win 同花顺 | Mac 同花顺 | Mac 通达信 | Android APP | **自建 B** |
|---|---|---|---|---|---|---|
| L1 涨速/涨幅/量比预警、弹窗/通知 | ✅ | ✅ | 部分 | 阉割版 | ✅（基础） | ✅ |
| L2 板块涨停家数、上涨家数占比 | ✅（自编横向统计公式，门槛高、盘中性能受限） | 部分 | ❌ | ❌ | ❌ | ✅ |
| 两级状态机 / L1 升级 L2 / 分级去重 | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |
| 推送到微信 | ❌（只弹自己客户端） | ❌ | ❌ | ❌ | ❌ | ✅ |
| 联动持仓/候选池、自动复盘 | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |

> 通达信实现 L2 的工具（仅 Windows 版）：横向统计函数 `HORCALC / INSUM / INSORT / BLOCKSETNUM`（官方提示"计算耗时大，慎用于实时画线"）、量化接口 `getbkjyvalue` 的涨停/上涨家数（BK9/BK12/BK13）、".400"板块分析页。能"看出"主线，但难以做成盘中自动、分级、推微信。

**设备建议**
- **Mac（你）**：通达信核心能力（公式/预警/横向统计）只在 Windows 版，Mac 版是阉割版，想跑得装虚拟机（Parallels/CrossOver），**不建议折腾**。用「同花顺 Mac 版」看盘 + 「Android 同花顺 APP」收 L1 基础预警（移动收通知、不用盯电脑）。
- **Windows（朋友）**：装「通达信金融终端」完整版，是现成软件的能力上限，可写横向统计公式。
- **Android 手机**：同花顺/通达信 APP 可设 L1 基础预警并推送到手机通知；但板块横向统计、两级条件、状态机做不了。
- **完整 L2 + 微信推送 + 联动复盘**：任何现成平台都给不了，**只有自建 B**。

## 2. B 轨：自建监测器

### 2.1 数据流与架构

**数据源（多源热备，不绑定东财；AkShare 已封装）**

| 数据源 | 板块(概念/行业)聚合 | 实时粒度 | 封 IP / 限流 | 角色 |
|---|---|---|---|---|
| 东方财富 | **最全**：概念+行业实时、涨停池 `stock_zt_pool_em` | L1 3 秒 | 较严：单 IP >5 次/秒可能临时封约 10 分钟；东财系接口共用风控、被封成片，停 30~60 分钟自动解 | 主源 |
| 腾讯财经 qt.gtimg.cn | 个股/指数强、板块弱 | L1 3 秒，横评"最快最稳" | 低：单入口约 600 次后限流，可多入口轮换 | 高频轮询 / 第一备份 |
| 新浪财经 hq.sinajs.cn | 个股/指数 | L1 3 秒 | 中：须带 Referer，否则 403 | 备份 |
| 同花顺 | 板块可作备选 | L1 3 秒 | 接口较封闭，AkShare 支持有限 | 板块备选 |

> 取数策略：东财为主拿板块聚合与涨停池；腾讯承担"尾盘/活跃时段高频轮询"；东财被限自动切 腾讯→新浪→同花顺板块。板块→成分股映射盘前拉一次、当日缓存。

**实时性（不比同花顺"天生慢"）**
- 交易所 Level-1 免费行情本身就是 **3 秒一帧快照**；同花顺/通达信/东财/腾讯/新浪免费端**底层同源、新鲜度上限相同（3 秒级）**。逐笔/秒级是付费 Level-2。
- 同花顺客户端由其服务器**持续推送**（打开即 3 秒跳动）；自建为**主动轮询**，延迟 ≈ 轮询间隔 + 3 秒。
- 为防封默认常规 60 秒、尾盘 30 秒；**借助腾讯源（限流宽松），活跃/尾盘可把轮询缩到 10~15 秒，体感逼近同花顺客户端**，被限即多源切换。
- 免费网页接口给不了同花顺那种"长连接持续推送"，但 5~15 秒轮询 + 状态机去重，对"板块爆发后约 1 分钟内知晓并推送"完全够用。

```
交易时段(9:30-11:30/13:00-15:00)
        │  每 60 秒一轮（尾盘 14:30 后 30 秒）
        ▼
[AkShare 拉取]
 ├─ 概念板块实时行情 stock_board_concept_spot_em（一次返回全部概念，每行一个板块）
 ├─ 行业板块实时行情 stock_board_industry_spot_em（一次返回全部行业）
 ├─ 涨停板池      stock_zt_pool_em（全市场当日涨停股：封单/连板/行业）
 └─ 成分映射（盘前构建、当日缓存）：stock_board_concept_cons_em → "股票→概念板块"
        ▼
[触发引擎] 对每个板块套用 L1/L2 规则 → 状态机去重
        ▼
[输出] ① 微信推送（企业微信机器人/Server酱）
      ② 留痕 data/intraday_alerts/YYYY-MM-DD.csv
        ▼
[盘后] 对接 daily-after-close：复盘触发板块 T+1/T+3/T+5 表现，统计胜率
```

**"一次覆盖所有板块"的原理**：板块实时接口一次返回一张大表（约 400 概念 + 86 行业，每行一个板块，自带涨幅/成交额/上涨下跌家数/领涨股），程序遍历每一行套同一套阈值，无需逐个配置；东财新建概念下次轮询自动纳入。涨停数由全市场涨停池 + "股票→板块"映射批量归类，一次算全。

### 2.2 专业触发方案（L1 抓突发 / L2 确认主线）

#### L1 · 异动预警（早期、灵敏）——满足任一即推【板块异动】
| 编号 | 条件 | 阈值（建议初值） |
|---|---|---|
| L1-a 涨速突发 | 板块 **10 分钟涨速**（两次快照差，自己算） | ≥ **1.5%**（尾盘可看 5 分钟 ≥1%） |
| L1-b 阈值初达 | 板块当日涨幅 **且** 涨停数 | 涨幅 > **2.5%** 且 涨停 ≥ **3** |

#### L2 · 主线确认（防一日游）——同时满足才推【疑似主线】
| 维度 | 条件 | 阈值（建议初值） |
|---|---|---|
| 强度 | 板块当日涨幅 | > **2.5%** |
| 广度 | 板块涨停家数 | ≥ **5**（职业投顾"主线入门"线） |
| 量能 | 板块量比 / 成交额 | 量比 ≥ **1.5**，或成交额 > 近5日同时段均值 ×1.5 |
| 广度 | 板块内上涨家数占比 | ≥ **60%**（防一两只权重拉指数） |

> 强信号（记录、可选触发）：板块涨停数占**全市场涨停总数 ≥15%** = 资金共识。
> 排雷：涨速快但成交额小、涨停少、上涨家数少 → 判"疑似一日游"，降级或不推 L2。

### 2.3 去重 / 状态机（防刷屏）
- 状态：`未触发 → L1已推 → L2已推`，当日状态写 JSON，收盘归档。
- 每板块每级别当天只推一次；L1 后升级 L2 再推一次。
- 条件全部消失（回落破阈值）后再次放量突破，L1 可再推一次（"二次启动"）；L2 当天不重复。

### 2.4 微信推送消息模板
```
【板块异动 · L1】
板块：海峡两岸（BK0xxx）
触发：10分钟涨速 +1.8%  （或：涨幅 +2.7%，涨停 3 只）
领涨：某某 +10.0% / 某某 +8.1% / 某某 +6.3%
时间：14:31

【疑似主线 · L2】（升级时追加）
涨幅 +3.6%｜涨停 6 只｜量比 1.8｜上涨 42/56
龙头：某某（2连板，封单1.2亿）｜补涨关注：某某、某某
```

### 2.5 部署（与下载同一套后台机制）
- 脚本：`scripts/intraday_sector_monitor.py`（常驻，内部判断交易时段、非时段休眠）。
- launchd：`com.astock-quant.intraday-monitor.plist`，`RunAtLoad=true`、`KeepAlive={SuccessfulExit=false}`（非0退出才重启），单例（锁文件 + launchd 单实例）。
- 凭证：webhook/key 放配置或环境变量（`.gitignore`），**绝不入库、不贴聊天**。

### 2.6 留痕 / 复盘 / 历史回测
- 留痕：`data/intraday_alerts/YYYY-MM-DD.csv`（板块、级别、触发时间、当时各指标、领涨股）。
- 盘后复盘：接 `daily_after_close`，自动算触发板块 T+1/T+3/T+5 收益，统计规则胜率/盈亏。
- 历史回测：用板块历史行情 `stock_board_concept_hist_em` + 历史涨停池（`stock_zt_pool_em(date=)`）回放，验证 L1/L2 在过去的表现，据此最终定阈值。

| 阶段 | 内容 | Owner | 依赖 | 工期 | 验收标准 |
