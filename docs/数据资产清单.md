## 二、数据频率说明

| 频率 | 说明 | 数据量（估算） | 适用场景 |
|---|---|---|---|
| **日线** | 每天一根K线（开高低收量） | 个股~500MB / ETF~30MB | 中低频策略（月度/周度调仓）、MVP |
| **5分钟线** | 每5分钟一根K线 | 个股~4GB / ETF~200MB | 中频策略（日内/小时级）、更精细回测 |
| **1分钟线** | 每分钟一根K线 | 个股~40GB / ETF~2GB | 高频/日内策略（当前项目不做） |
| **Tick数据** | 每笔成交 | 个股~TB级 | 超高频（当前项目不做，且免费数据源拿不到） |

### 3.2 关键口径澄清（2026-09-20 对话沉淀，避免新会话/换设备误会）

**① 个股行情K线只有两种；财务三表不是K线，是另一类**
- 行情K线：**日线、5分钟线**。
- `profit/growth/dividend` 是公司财报（ROE、净利润增速、现金分红），**不是行情**，是算选股因子的原料。

**② 为什么日线和5分钟线都要，不能只要5分钟线**

| | 日线 | 5分钟线 |
|---|---|---|
| 历史长度 | 2001起（~25年） | **只2020-01起（~6年）** |
| 覆盖2015起回测 | ✅ 全程 | ❌ 2015–2019 无数据 |
| 一只股票行数 | ~6000行 | ~7.8万行（十几倍） |
| 当前用途 | **回测主力**（月度调仓只需日线） | 将来日内/中频策略预留 |

> 理论上5分钟线可聚合成日线，但历史太短、数据量太大，且当前是月度调仓用不上，故不能互相替代。

**③ 中证800日线 vs 全市场日线：不是两份数据，是子集**
- 中证800的 **706只 ⊆ 全市场4889只**（沪深300∪中证500，剔科创板）。
- 两者写**同一目录同一套文件名** `data/raw/daily/{sh,sz}/{code}.csv`。
- 清单分两行只是**跟踪目的不同**：706只是D策略硬依赖，必须100%下完✅；其余4000只是长期储备⏸️。
- 重叠317只是两条线都碰过同一只股票，写同一文件，**不占双倍空间**。

**④ 文件格式与"为什么不冗余"**
- **一只股票一个CSV**（不是所有股票合成一个大表）：`data/raw/daily/{sh,sz}/{code}.csv`。
- 每行=一个交易日，17列（开高低收量额/前复权/换手/涨跌停与停牌状态/PE-PB）。
- 下载=**整段重拉 + 整个文件覆盖写**（`df.to_csv`，不是追加）；断点续传也是"新旧合并去重后整个写回"。
- 数据源与参数相同 → 同一只股票无论被几条线碰过，磁盘上永远只有它一个最新完整CSV，**不存在"合并"这一步**。

**⑤ 什么是当前刚需、什么是长期储备**
- D回测地基（已备齐）：中证800日线✅ + 财务三表✅ + 沪深300基准✅（正式回测已出，见 TASK_STATUS G2）。
- 已验证挂起：股吧采样（C舆情因子）。
- 长期储备（后台慢补、现在不用）：全市场日线（31%）/全市场5分钟线（24%，最大头9.2G）。
