# 参与者画像与角色定位 · astock-quant

> 这份文档给"刚介入的第三方"看：**这项目里有哪些参与者、各自是谁、扮演什么角色、风格偏好是什么、该怎么和他/它打交道。**
> 第三方读了它，才知道"该听谁的判断、谁拍板、谁是经验来源"，而不是对着一堆文档不知道信谁。
> 同时它本身是个 **SOP**：新增参与者时，按下面的字段补一条。

---

## 0. 怎么维护这份画像（SOP）

- **什么时候更新**：发现某人的风格、偏好、角色有新认识时（比如用户某次决策暴露了新偏好）。
- **每条画像必写字段**：①身份 ②在项目中的角色 ③风格/偏好 ④协作方式 ⑤和他/它打交道的注意点。
- **谁来填**：AI 根据历史讨论提炼，用户确认。
- **隐私红线**：不写真实姓名、联系方式等隐私，只写"协作需要的画像"。操盘手 nero6688 是他公开的昵称，可保留。
- **易变的不写死**：当前在做什么、进度，以 `TASK_STATUS.md` 和 `HANDOFF.md §3` 为准，这里只写"稳定的画像和角色"。

## 2. 详细画像

### 2.1 用户（项目 owner / 决策者）

| 字段 | 内容 |
|---|---|
| **身份** | 个人投资者，本量化项目发起人；非量化科班出身 |
| **角色** | 唯一决策者（R=A）：拍板方向、策略参数、边界；执行细节授权 AI |
| **决策风格** | 果断、高度授权——"按你的节奏来""你自己安排""1,3,4""我认可1"。重大方向自己定（C→D→B 顺序、候选池、防御资产），细节放手让 AI 跑 |
| **沟通偏好** | ① 要大白话，不要工程腔（"能不能用大白话讲一下"）；② 喜欢表格、一张表分阶段看；③ 极度重视文档化和沉淀（"做下沉淀""记录进项目管理清单"）；④ 会反思流程本身（"需求流程是不是乱了""要不要你来纠偏"） |
| **工作方式** | ① 后台跑、不被打扰（"下载自己安排，别让我过多干涉"）；② 控制数据量（"不可能为了需求拿过大数据"）；③ 要单一真相源（反复要求合并文档、一张表分阶段） |
| **技术水平** | 有一定理解但非专业出身，会追问基础概念（"沪深300是什么""为什么有日线还要5分钟"）——讲清楚即可，**不要默认他懂术语** |
| **打交道注意点** | ① 结论先给一句话再展开；② 他跑偏时主动拉回主线（这是他明确要求的）；③ 不确定就说不确定，不编造；④ 重大决策留给他拍板，执行层别替他定 |

### 2.2 操盘手 nero6688（大海星）· 方法论来源

| 字段 | 内容 |
|---|---|
| **身份** | 非量化出身的散户操盘手，有业内朋友可咨询 |
| **角色** | **不是直接协作者，是方法论来源**——他的 124 个豆包对话已沉淀为项目的经验输入 |
| **风格** | 价值投资为主 + 技术形态辅助，中低频，左侧布局 |
| **核心方法** | 六层价值过滤系统（业务→护城河→管理层→财务→疑点→估值）；双策略：1号左侧困境反转、2号底部突破 |
| **工具习惯** | 豆包重度用户；每日盘后复盘、反复做"数据复核" |
| **打交道注意点** | ① 他的经验是"输入"不是"指令"——用历史数据验证，不盲从；② 他反复强调数据准确性，这也是我们的硬要求；③ 他踩过的坑（回测虚假收益、纯技术面陷阱、冲击成本）我们必须避开 |
| **详见** | `09_调研底稿与素材/操盘手经验/操盘手经验沉淀与需求输入.md` |

### 2.3 AI（doubao）· 执行者 + 分析师 + 项目经理

| 字段 | 内容 |
|---|---|
| **身份** | 本项目的执行 AI；当前 G2 阶段扮演：量化开发 + 测试 + 分析师 + 文档治理 |
| **职责** | ① 数据下载与维护（后台、断点续传、防限流）；② 回测引擎开发与结果解读；③ 需求梳理、文档治理、阶段纠偏 |
| **工作方式** | 自主推进、少打扰用户；记录决策（ADR）；维护单一真相源；诚实标注局限（幸存者偏差、舆情因子做不通） |
| **边界** | 不替用户做投资决策、不给买卖建议；不编造；用户问题按 `WORKFLOW.md` §0 四分类（影响主线/概念好奇/远期/状态查询）处理并纠偏 |

## 3. 协作关系图（谁和谁怎么配合）

```
        用户（拍板）
         │ 方向/参数/边界
         ▼
   AI（执行+分析+文档）
     │            │
     │ 经验输入    │ 产出/解读
     ▼            ▼
操盘手经验      用户确认后落地
(124对话沉淀)   （回测→模拟盘）
```

- **用户**定方向和决策，**AI**负责把方向落成代码、数据、文档，并在跑偏时拉回用户主线；**操盘手经验**是输入素材（不是指令），用历史数据验证后才进系统；**第三方**通过 HANDOFF + 本画像快速进入。
