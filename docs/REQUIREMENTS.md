## 1. 项目背景与目标

### 1.1 背景
用户是A股投资者，希望搭建一套基于纯开源框架的量化交易系统，融合AI大模型做舆情/文本因子。当前市场上的量化系统要么闭源昂贵、要么功能复杂难以上手、要么缺乏AI因子能力。用户希望从自身需求出发，逐步构建一套可落地、可迭代的个人量化系统。

### 1.2 目标
- 搭建一套基于纯开源框架的A股量化交易系统
- 融合AI大模型做舆情/文本因子
- 从回测到盘后信号推送，小资金可落地
- 形成可复用的项目文档和操作手册

### 1.3 非目标（不做什么）
- ❌ 不做高频交易（中低频为主）
- ❌ 不碰券商闭源终端（QMT/PTrade）
- ❌ 不做自动下单（起步阶段盘后信号+人工下单）
- ❌ 不替用户做投资决策、不承诺收益
- ❌ 不做港股/美股/期货（聚焦A股，含ETF）

## 2. 用户与场景

- **目标用户**：用户自己（个人投资者，有Python基础）
- **核心场景**：
  - 盘后：自动下载当日数据、运行策略、生成交易信号
  - 周末：策略复盘、参数调优、因子有效性检验
  - 调研期：框架对比、方案选型、数据准备
- **不服务谁**：机构投资者、团队协作、多账户管理

## 3. 功能需求清单

### P0（必须有，没有就不能用）

| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F-001 | A股历史数据下载 | 从Baostock下载全量A股日线/财务/复权因子数据，覆盖1990年至今 | 数据覆盖率≥95%，脚本可复现，断点续传 |
| F-002 | 数据增量更新 | 每日收盘后只下载新增数据，不重复下载 | 增量更新可自动运行，数据不重复 |
| F-003 | 开源量化框架选型 | 对比vn.py/QuantDinger/qlib/Hikyuu/Backtrader，选定主框架 | 有对比报告，有推荐理由，最小demo跑通 |
| F-004 | 最小可用策略 | 实现一个完整链路：数据获取→因子计算→回测→信号输出 | 回测覆盖≥3年，绩效指标完整，策略可复现 |
| F-005 | 回测引擎 | 支持A股回测（复权、手续费、滑点、仓位管理） | 回测结果合理，与基准对比有意义 |
| F-006 | 盘后信号生成 | 每日收盘后运行策略，产出交易信号报告 | 信号包含标的/方向/理由/仓位，可自动生成 |

### P1（应该有，没有会很不方便）

| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F-101 | AI 舆情因子 | 用大模型对新闻/公告/社交媒体做舆情打分，作为因子输入 | 因子有定义、有回测验证、有效性能说明 |
| F-102 | 因子库 | 基础因子（动量/价值/质量/波动率）+ AI因子，可扩展 | 每个因子有文档，可独立回测 |
| F-103 | 数据质量监控 | 自动检测数据缺失、异常、延迟 | 有质量报告，异常有告警 |
| F-104 | 参数敏感性分析 | 关键参数对绩效的影响分析 | 有敏感性图表，有稳健性判断 |
| F-105 | 模拟盘跟踪 | 用模拟盘跟踪信号表现 | 有模拟盘记录，可与回测对比 |

### P2（可以有，有余力再做）

| 编号 | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F-201 | 实盘小资金验证 | 人工下单，小资金试跑 | 有实盘记录，与模拟盘对比 |
| F-202 | 策略迭代管理 | 策略版本管理、迭代记录、A/B对比 | 有版本记录，可回溯 |
| F-203 | 多策略组合 | 多个策略组合运行，仓位分配 | 有组合绩效，有归因分析 |
| F-204 | 可视化看板 | 策略绩效、信号、持仓的可视化 | 有Web或Notebook看板 |
| F-205 | 自动下单评估 | 评估自动下单的可行性和风险 | 有评估报告，有安全方案 |

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 全量回测（3年+全A股）≤ 30分钟；每日数据下载 ≤ 1小时 |
| 数据完整性 | 日线数据覆盖 ≥ 95% 交易日；财务数据覆盖主要指标 |
| 可维护性 | 代码模块化，新增策略只需加一个文件；新增因子只需加一个函数 |
| 可复现性 | 所有回测参数固定、数据固定、结果可重跑；环境可复现（requirements.txt） |
| 安全性 | API key 不入库，凭证加密；不做自动下单（起步阶段） |
| 兼容性 | Python 3.10+，macOS/Linux；双机同步（cw + wj） |
| 成本 | 数据免费（Baostock）；AI API 按量付费，控制成本 |

## 6. 依赖与约束

- **外部依赖**：Baostock API（免费）、Python 生态（pandas/numpy）、选定的量化框架
- **技术约束**：纯开源框架，不使用付费量化平台；数据免费，不购买付费数据
- **资源约束**：本地运行（Mac），不依赖云服务器；双机同步（cw + wj）
- **合规约束**：不做投资建议、不承诺收益；个人学习研究用途
- **选型约束**：框架和AI方案选型必须有对比报告，决策留给用户（调研期不替用户决定）
