## 一、股吧散户情绪指数（反向指标）

### 1.1 核心逻辑

| 现象 | 含义 | 操作信号 |
|---|---|---|
| 股吧近几天交流活跃、说话的人多 | 散户情绪高、狂热 | ⚠️ 可能见顶，减仓/卖出 |
| 股吧几天没人说话、冷清 | 散户情绪低、绝望 | ✅ 可能见底，加仓/买入 |

> **本质**：散户是市场的"反向指标"——散户狂热时往往是顶部，散户绝望时往往是底部。

### 1.2 数据来源

| 平台 | 网址 | 数据内容 |
|---|---|---|
| 东方财富股吧 | guba.eastmoney.com | 个股股吧的发帖量、评论量、浏览量、活跃用户 |
| 同花顺股吧 | guba.10jqka.com.cn | 同上（备选，交叉验证） |

### 1.3 情绪指数计算方法

**基础指标（每日采集）**：
- 当日发帖数（主帖+回帖）
- 当日浏览量
- 当日活跃用户数（去重）

**情绪指数合成**：
```
情绪指数 = 近5日平均发帖量 / 过去60日平均发帖量 × 100
```

- 指数 > 150：情绪极高（散户狂热，警惕见顶）
- 指数 80-150：情绪正常
- 指数 < 80：情绪极低（散户绝望，关注见底机会）

**备选指标**：
- 换手率（可从K线数据直接算，作为情绪的代理指标）
- 成交量变化（放量=情绪高，缩量=情绪低）
- 融资余额（需要额外数据源）

### 1.4 因子用法

| 用法 | 说明 |
|---|---|
| **个股择时** | 单只股票股吧情绪极高时卖出，极低时买入 |
| **市场择时** | 全市场股吧整体情绪极高时减仓，极低时加仓 |
| **ETF轮动辅助** | 在ETF轮动策略中，加入情绪过滤：情绪极高时不追涨，情绪极低时敢于买 |
| **多因子选股辅助** | 选股时排除情绪极高的股票（避免追高），优先选情绪极低的股票（抄底） |

## 二、历史数据验证方案

### 2.1 验证目标

验证"散户情绪是反向指标"这个逻辑是否成立：
- 情绪极高时，后续股价是否下跌？
- 情绪极低时，后续股价是否上涨？

### 2.2 第一轮验证结果（2026-09-18，用K线数据间接验证）

**验证方法**：用成交量/换手率作为散户情绪的代理指标，478只股票，300万条记录

**关键结论**：

| 时间窗口 | 反向指标是否成立 | 说明 |
|---|---|---|
| 未来5日 | ❌ 不成立 | 短期"高"组收益最高（动量效应，放量后短期继续涨） |
| 未来10日 | ❌ 不成立 | 同上，短期动量效应主导 |
| 未来20日 | ✅ 成立 | 极低组收益显著高于极高组（+0.12%~+0.28%） |

**详细数据（成交量代理）**：

| 分组 | 未来5日 | 未来10日 | 未来20日 | 20日胜率 |
|---|---|---|---|---|
| 极低（缩量=情绪低） | 0.26% | 0.49% | **1.38%** | 47.6% |
| 低 | 0.36% | 0.70% | 1.48% | 50.5% |
| 中 | 0.36% | 0.77% | 1.53% | 50.5% |
| 高 | 0.49% | 0.92% | 1.64% | 50.3% |
| 极高（放量=情绪高） | 0.35% | 0.74% | **1.25%** | **48.3%** |
| 多空差（极低-极高） | -0.10% | -0.25% | **+0.12%** | - |

**核心洞察**：
1. **方向正确，但有时间差**：散户情绪反向指标在中长期（20日+）成立，短期不成立
2. **短期是动量效应**：放量后短期可能继续涨（突破/追涨），持续放量后才会见顶
3. **极高组胜率最低**：极高组20日胜率只有48.3%，中位数收益为负，说明极度狂热后确实容易亏钱
4. **因子用法调整**：不要用单日情绪，要用"持续N天情绪极值"（比如连续5天放量才触发见顶信号）

**验证脚本**：`scripts/verify_sentiment_contrarian.py`
**验证结果**：`results/sentiment_verification/`

### 2.3 验证路径（分两步走）

#### 第一步：用K线数据间接验证（✅ 已完成，见2.2）

我们已经有大量K线数据，可以用**成交量/换手率**作为散户情绪的代理指标，验证类似逻辑。

#### 第二步：用真实股吧数据验证（⏳ 待积累数据）

1. 写爬虫采集东方财富股吧数据（每日发帖量、评论量等）
2. 积累至少3-6个月数据
3. 用真实情绪指数重复第一步的验证方法
4. 对比"真实股吧情绪"和"成交量代理"哪个预测效果更好

> 预期：真实股吧情绪效果可能更好，因为成交量包含了机构和散户，而股吧情绪更纯粹是散户。

## 三、模拟盘设计

### 3.1 模拟盘定位

- **目的**：在真金白银实盘之前，先用模拟盘验证策略的实盘表现
- **策略**：先跑 ETF 轮动策略（MVP），后续加多因子选股
- **周期**：至少跟踪 1-3 个月，确认策略稳定后再考虑小资金实盘

### 3.2 模拟盘运行机制

| 环节 | 说明 |
|---|---|
| **信号生成** | 每日盘后（15:00后）运行策略，生成次日调仓信号 |
| **信号推送** | 微信推送次日买卖信号（ETF代码、操作方向、目标仓位） |
| **模拟执行** | 按次日开盘价模拟成交（扣除交易成本） |
| **持仓记录** | 每日记录模拟持仓、净值、现金、收益 |
| **每日复盘** | 13:30前输出当日复盘（持仓涨跌、净值变化、信号状态） |
| **绩效跟踪** | 累计收益、年化收益、最大回撤、夏普比率、胜率 |

### 3.3 模拟盘数据结构

```
模拟盘账户
├── 初始资金：1,000,000 元（虚拟）
├── 当前持仓：[{code, name, 数量, 成本价, 现价, 市值, 盈亏}, ...]
├── 可用现金：xxx 元
├── 总市值：xxx 元
├── 累计收益：xxx 元（xx%）
├── 历史净值：[{date, 净值, 收益率}, ...]
└── 交易记录：[{date, code, 方向, 价格, 数量, 手续费}, ...]
```

### 3.4 模拟盘与实盘对比

| 对比项 | 模拟盘 | 实盘 |
|---|---|---|
| 成交价 | 次日开盘价 | 实际成交价（可能有滑点） |
| 交易成本 | 佣金万2.5（模拟） | 实际佣金 |
| 成交确定性 | 100%成交 | 涨跌停可能无法成交 |
| 心理压力 | 无 | 有（影响执行） |

> 模拟盘和实盘的主要差异是**滑点**和**心理因素**。模拟盘跑通后，小资金实盘验证滑点影响。
