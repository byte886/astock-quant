## 1. 策略总览

两个**相互独立、各自等权持仓**的单因子策略，统一回测框架、统一股票池、统一交易规则，仅因子不同：

| 策略 | 因子 | 一句话逻辑 | 典型持仓行业 |
|---|---|---|---|
| **价值策略** | **股息率**（过去12个月现金分红/股价） | 买持续高分红的便宜蓝筹，赚分红+估值回归 | 银行、能源、公用事业、交运、家电 |
| **成长策略** | **净利润同比增速排名 + ROE≥10% 质量门槛** | 买"高ROE且利润仍在快速增长"的优质公司 | 食品饮料、医药、新能源、电子、高端制造 |

> 成长因子口径（已与用户确认，2026-09-19）：采用**净利润同比增长率（YOYNI）排名**，并以 **最新一期 ROE≥10%** 作为质量门槛；不采用"ROE 同比提升幅度"（该口径易选出扭亏周期股，噪声大）。

## 2. 股票池

- **中证800 = 沪深300 ∪ 中证500，剔除科创板（sh.688）**，约 **706 只**。
- 选它的理由：中大盘、流动性好、财务数据质量高、机构覆盖充分，天然排除小盘壳股/次新垃圾股，契合"价值投资、中低频"定位。
- **动态成分股（防幸存者偏差）**：每个调仓日取**当时**的指数成分股（baostock `query_hs300_stocks(date=...)` / `query_zz500_stocks(date=...)`），不用最新成分股回测历史。

### 调仓日硬性过滤（在股票池基础上再剔除）
1. ST / *ST / 退市整理（`isST=1`）；
2. 上市不满 1 年（次新股，财务不稳定）；
3. 调仓信号日停牌、或目标成交日停牌（无法成交，保留原持仓）；
4. 买入时一字**涨停**（封死涨停板，买单排不上，买不进，放弃本次买入）；卖出时一字**跌停**（封死跌停板，卖单排不上，卖不出，继续持有）；
5. 价值策略额外要求：**连续 3 个完整年度有现金分红**（防一次性高分红陷阱）；
6. 成长策略额外要求：**最新一期 ROE ≥ 10%**、近两期净利润为正。

## 3. 因子定义（严格 PIT）

### 3.1 价值因子：股息率（Dividend Yield）

```
股息率 = 过去12个月已实施的每股现金分红（税前）之和 / 信号日收盘价
```

- 分红取 baostock `query_dividend_data` 的 `dividCashPsBeforeTax`（每股税前现金分红）；
- **只统计除权除息日（dividOperateDate）早于信号日的分红**——预案公告了但还没实施的不计入；
- 已含中期分红（部分公司一年派息 2 次，需累加，如工行 2024 年有年报+中报两次）；
- 连续 3 年分红过滤：近 3 个完整年度每年 `dividCashPsBeforeTax` 之和 > 0；
- 排名：股息率从高到低，取前 15 只。

### 3.2 成长因子：净利润同比增速（+ROE 质量门槛）

```
成长得分 = 最新财报 净利润同比增长率 YOYNI（query_growth_data）
质量门槛：最新一期 ROE（roeAvg，加权平均）≥ 10%
```

- YOYNI = 净利润同比增长率；ROE = `query_profit_data.roeAvg`；
- 财报按 **pubDate（实际披露日）** 对齐：信号日只能使用**已披露**的最新一期财报，杜绝用了当时尚未公布的数据；
- 排名：在通过质量门槛的股票中，按 YOYNI 从高到低取前 15 只；
- 数据缺失（金融类部分字段、财报未披露）的股票当期不参与排名。

## 4. 调仓与交易规则

| 项目 | 规则 |
|---|---|
| 调仓频率 | **月度** |
| 信号日 | 每月最后一个交易日（盘后，用截至当日全部已披露数据算因子） |
| 成交日 | **次月第一个交易日，以开盘价成交**（避免使用当日未来信息） |
| 持仓数量 | 每策略 **15 只，等权**（单只初始约 6.67%） |
| 换仓规则 | 新榜单与现持仓比较，保留仍在榜的，卖出掉出的，买入新进入的，等权再平衡 |
| 停牌/涨跌停 | 目标股买不进则放弃本次买入（现金留存）；持仓卖不出则继续持有 |
| 初始资金 | 100 万元（与模拟盘一致，两策略各自独立 100 万或合并 200 万，回测时分别计） |

### 交易成本（A股真实口径，偏保守）
- 佣金：双边各 **万分之 2.5**（万2.5），单笔最低 5 元；
- 印花税：**卖出金额的 0.1%**（千1，2023-08 后减半为 0.05%，回测可分段，默认统一千1保守处理，敏感性另测）；
- 滑点：成交价额外 **千分之 1**（开盘价 ±0.1%）；
- 过户费等小额费用忽略。

| 项目 | 设置 |
|---|---|
| 回测区间 | **2015-01-01 ～ 2026-09-19**（约 11.7 年，财务数据自 2015 完整） |
| 覆盖周期 | 2015 杠杆牛/股灾、2018 熊市、2019-2020 核心资产牛、2021 结构牛、2022-2024 熊、2024-09 反弹 |
| 基准 | **沪深300**（sh.000300 / ETF sh.510300） |
| 价格数据 | 中证800成分股**日线、前复权**（adjustflag=2），月度调仓无需分钟线 |
| 财务数据 | 季度 ROE/YOYNI、年度分红，按 pubDate/除息日 PIT 对齐 |
| 净值 | 日频盯市（按收盘价），交易在调仓日开盘 |

### 绩效指标
年化收益、年化波动、**最大回撤**、夏普比率、卡玛比率（年化/最大回撤）、胜率（月度）、平均持仓数、年化换手率、相对沪深300超额收益、超额回撤。

### 可视化（用户明确要求，简洁不做复杂仪表盘）
1. **净值曲线**：价值策略 / 成长策略 / 沪深300 三条曲线叠加；
2. **回撤图**：两策略的水下曲线（underwater）；
3. 年度收益柱状图（策略 vs 基准，可选）。

## 8. 已知风险与局限（诚实清单）

1. **高股息陷阱**：股息率高可能是股价暴跌被动抬高（分母跌），连续3年分红过滤只能部分规避；回测需观察"高股息+股价趋势"。
2. **成长股回撤大**：YOYNI 高的股票估值贵、业绩不及预期杀跌猛，成长策略最大回撤可能显著大于价值策略。
3. **财报滞后与修正**：季报有披露窗口（年报最晚4月底），PIT 对齐后因子更新慢；业绩快报/预告未纳入。
4. **行业集中**：价值会高度集中银行/能源，成长集中少数赛道，等权个股但行业未中性化，波动来自行业 Beta。
5. **样本与制度变化**：2015 年中证500成分、分红制度（中期分红近年才普及）与现在有差异，早期结果代表性弱。
6. **单因子**：本阶段刻意保持单因子透明可解释；行业中性、多因子合成留待后续。
