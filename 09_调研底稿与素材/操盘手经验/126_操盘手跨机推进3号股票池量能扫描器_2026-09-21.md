## 一、他在那台机让 AI 做了什么

1. 从 GitHub 拉取 `byte886/astock-quant`（仓库很小，约 1.2MB / 201 个文件，不含行情大数据）。
2. zip / raw 下载通道超时、raw 域名被 DNS 污染，改用 **api.github.com Contents API** 逐个取关键文档（策略、ADR、任务状态、3 号股票池素材、模拟盘脚本）。
3. 通读操盘手素材，**对齐编号体系**（结论与本仓经验 003/004 原文一致）：
   - 1 号策略 = 左侧困境反转；2 号策略 = 右侧突破波段；3 号 = 量能筛选股票池（注意那台机 AI 有一处把 2 号写成"底部突破"，**以经验 004 原文"右侧突破波段"为准**）。
   - 3 号池归档清单 **55 个标的（53 只个股 + 2 只 ETF）**，9-10 基准约 52 只个股 + 2 只 ETF。
4. 写了一个批量扫描脚本 **`pool3_scan.py`（+117 行）**：内置 55 个标的，指标含 **TRIX、均线、量比、突破、试盘、位置、支撑/压力**全套；目标是用截至上周五（9-18）收盘的日线，套规则给每只标的评级。
