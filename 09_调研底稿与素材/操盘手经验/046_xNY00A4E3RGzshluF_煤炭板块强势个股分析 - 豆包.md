板块 20 日乖离率（BIAS20）完整看懂教程
一、先懂公式与基础含义
计算公式
BIAS20 = (板块指数收盘点位 − 20 日均线点位) ÷ 20 日均线点位 × 100%
正数（正乖离）：板块指数站在 20 日均线上方，短期上涨，数值越大越超涨、获利盘越重；
负数（负乖离）：板块指数跌破 20 日均线，短期下跌，数值越小越超跌、抛压充分释放；
0 轴：指数刚好等于 20 日平均成本，多空均衡分界线。
20 日乖离定位
专门看1~3 个月中期波段，比 5/10 日稳定、比 60 日灵敏，最适合行业板块高低点轮动判断。
二、板块通用参考阈值（分波动类型）
板块分低波动防御板块、高波动成长题材板块两套标准，直接套用：
1）低波动板块（煤炭、银行、消费、红利、公用，如中国神华所属煤炭）
20 日乖离临界：
+5% 以上：中期超买，板块短期积累大量获利盘，极易出现波段回调；
+2%~+5%：健康多头区间，趋势完好，可持有；
-2%~+2%：震荡中性，无明确方向；
-5% 以下：中期超卖，空头动能充分释放，存在修复反弹机会；
-7% 以下：极端超卖，反弹概率极高。
2）高波动板块（零售、半导体、AI、新能源、医药小票，红旗连锁所属消费零售）
波动更大，阈值放宽：
+8%~+10%：超买预警，追高风险极大；
-8%~-10%：超卖区间，适合分批低吸博弈反弹；
±3% 以内：震荡整理区间。
补充：强势主线牛市阶段，阈值可上浮 2%；熊市轮动弱势板块，阈值收紧 2%
三、四步完整看盘逻辑（实战核心）
第一步：判断 0 轴趋势，定板块大方向
BIAS20 持续在 0 轴上方：板块中期多头趋势，回调到 0 轴附近常是低吸点；
BIAS20 持续在 0 轴下方：板块中期空头趋势，反弹到 0 轴附近是压力，不宜重仓抄底；
从负区间上穿 0 轴：趋势由空转多，波段启动信号；
从正区间跌破 0 轴：趋势由多转空，波段结束减仓信号。

信号 1：高位正乖离（减仓 / 回避追涨）
板块连续拉升，BIAS20 突破对应阈值，价格大幅偏离 20 日平均成本，获利盘兑现压力大：

消费 / 科技（红旗连锁板块）BIAS20＞+9% → 禁止追高，等待回调修复。
