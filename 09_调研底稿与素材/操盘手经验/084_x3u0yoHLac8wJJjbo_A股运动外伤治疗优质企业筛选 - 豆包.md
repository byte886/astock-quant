A 股运动外伤治疗优质企业筛选（分两大赛道：手术器械耗材 + 外用 / 内服骨伤药物）
运动外伤分为两类：重度软组织 / 韧带 / 半月板手术修复（高值耗材赛道，高成长、国产替代空间大）、轻度扭伤挫伤消肿止痛 OTC / 中成药（刚需、现金流稳、低集采压力），下面精选基本面、技术壁垒、业绩增速、财务质地最优标的，附核心逻辑与风险。
一、运动医学手术耗材龙头（重度运动损伤手术：韧带、半月板、肩袖撕裂）
1. 威高骨科（688161）【综合质地第一，全骨科平台 + 运动医学爆发】
核心产品：交叉韧带重建、半月板修复、锚钉、可吸收螺钉、关节镜配套器械，覆盖膝 / 肩 / 踝全运动损伤场景
质地亮点：
国内骨科全品类龙头，运动医学产品线完整，2026Q1 运动医学收入同比+236%，增速行业第一；
研发实力强，3D 打印、生物活性材料储备足，国家级创新企业，医院渠道覆盖全国三甲；
集采冲击对冲能力强，创伤 / 关节 / 脊柱基本盘稳固，海外业务高速增长平滑国内周期；
财务健康，毛利率稳定、现金流充沛，资产负债率低。
核心逻辑：平台型龙头，运动医学第二增长曲线兑现，国产替代加速。
2. 大博医疗（002901）【高研发、耗材矩阵完善，弹性强】
核心产品：带线锚钉、带袢钛板、半月板缝合系统、运动创伤接骨板，兼顾骨折 + 软组织损伤
质地亮点：
近千人大研发团队，1200 + 医疗器械注册证，运动医学取证速度行业靠前；
创伤基础盘扎实，运动医学耗材毛利率 70%+，盈利能力优异；
布局再生医学、创面修复，延伸运动损伤术后修复全链条；
民营医院渠道优势明显，增量空间充足。
3. 凯利泰（300326）【运动医学先行者，子公司利格泰专攻人工韧带】
核心产品：锚钉、半月板修复、人工韧带（利格泰）、关节镜耗材，国内最早布局运动医学民企
质地亮点：
脊柱微创打底，历史减值出清，2023 年净利润同比暴增 628%，盈利修复完成；
人工韧带国产稀缺标的，运动损伤高端耗材壁垒高；
资产负债率低，经营性现金流持续为正，估值性价比突出。
4. 春立医疗（688236）【关节龙头延伸运动医学，微创配套齐全】
核心产品：软组织修复植入物、关节镜系统、富血小板血浆修复设备（运动软骨修复）
质地亮点：人工关节单项冠军，骨科临床资源深厚，运动医学作为第二曲线稳步放量，海外出口持续放量。
二、运动外伤内服 / 外用药物龙头（轻度扭伤、拉伤、肿痛，居家 / 门诊刚需）
1. 羚锐制药（600285）【骨科外用贴膏绝对龙头，现金流之王】
核心产品：通络祛痛膏、壮骨麝香止痛膏，专门针对运动扭伤、肌肉劳损、关节肿痛，OTC 全覆盖药店、运动场馆、医院康复科
质地亮点：
贴膏毛利率近 80%，现金流极其稳定，无集采大幅降价压力；
通络祛痛膏年销 12 亿 +，运动损伤外用市占 40% 以上；
管理层稳定，持续分红，业绩常年稳健增长，波动极小。
2. 云南白药（000538）【运动外伤急救第一品牌，全国认知度最高】
核心产品：云南白药气雾剂、白药膏、胶囊，运动扭伤、磕碰出血首选，健身房、运动队标配
质地亮点：品牌壁垒无可替代，全国渠道全覆盖，骨伤止血消肿赛道绝对龙头，估值低位，分红稳定。
3. 奇正藏药（002287）【高端外用贴膏，医院运动康复科放量】
核心产品：消痛贴膏（运动损伤专家共识推荐）、青鹏软膏，藏药配方止痛消肿效果突出，三甲康复科标配
质地亮点：院内渠道强势，毛利率 75%+，业绩稳步增长，独家藏药品种竞争格局好。
4. 盘龙药业（002864）【骨伤口服中成药独家品种】
核心产品：盘龙七片（医保甲类独家），骨折、软组织挫伤恢复期口服修复，适配运动损伤术后恢复
质地亮点：细分骨伤口服赛道小龙头，独家专利品种，院内刚性需求，业绩弹性充足。

四、赛道核心风险提示
骨科耗材：高值耗材集采常态化，产品降价压制利润率，依赖放量对冲；外资品牌临床壁垒仍高，国产替代进度不及预期。
外用中成药：OTC 竞争加剧，渠道费用抬升；中药原材料价格波动影响毛利。
行业共性：全民健身政策落地节奏、医院运动医学科室扩张速度不及预期。
